## Перевірка безпеки — практична робота №15

### XSS

Під час тесту відображення тексту нотатки через `innerHTML` тестовий HTML-рядок виконався в браузері. Вразливе місце виправлено: текст нотатки виводиться через `textContent`. Після виправлення той самий рядок відображається як звичайний текст, без виконання HTML.

### Сховища даних

У `localStorage` для `localhost:3000` виявлено технічний прапорець `isMigrated`. У `IndexedDB` (`NotesDB`, сховище `notes`) зберігаються нотатки. Під час перевірки тестове значення пароля було видно у відкритому вигляді. Реальні паролі не використовувалися. Навчальний застосунок не слід використовувати для зберігання справжніх паролів; для цього потрібне шифрування даних і захищене керування ключем.

### Захардкоджені секрети

Пошук у коді за словами `apiKey`, `api_key`, `token`, `secret`, `Authorization` і `Bearer` не виявив збігів із реальними ключами чи токенами. Збіги за словом `password` стосувалися полів форми та змінних.

### HTTPS

Для майбутнього розгортання обрано Vercel, що підтримує Express і HTTPS. Застосунок опубліковано на Vercel: https://notes-manager-neon.vercel.app/.
